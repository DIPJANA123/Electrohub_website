🆘 Help Center

Apni problem select karo aur complete solution dekho.

📦 Order kaise place karein?

▼

Order place karne ke steps:

  1. Homepage par jao.
  2. Search bar se apna product search karo.
  3. Product par click karke product details dekho.
  4. Order Now ya Add to Cart par click karo.
  5. Agar login nahi ho to apne account mein login karo.
  6. Delivery address aur phone number enter karo.
  7. Payment method select karo.
  8. Place Order par click karo.
  9. Order successfully place hone ke baad tum ise My Orders mein dekh sakte ho.

🚚 Order ko track kaise karein?

▼

Order track karne ke steps:

  1. Apne account mein login karo.
  2. My Account open karo.
  3. My Orders par click karo.
  4. Jis order ko track karna hai us order ko dekho.
  5. Order ke andar tracking timeline दिखाई देगी.

Tracking mein order ke different stages dikh sakte hain:

  • ✓ Order Placed
  • ✓ Confirmed
  • ✓ Shipped
  • ✓ Out for Delivery
  • ✓ Delivered

💳 Payment kaise karein?

▼

ElectroHub par available payment methods:

  • 💵 Cash on Delivery (COD)
  • 📱 UPI

Payment method select karne ke steps:

  1. Checkout page open karo.
  2. Delivery details enter karo.
  3. Payment method select karo.
  4. Order place karo.

🔄 Replacement kaise request karein?

▼

Agar delivered product damaged, wrong ya defective hai, to replacement request ki ja sakti hai.

Replacement request ke steps:

  1. Apne account mein login karo.
  2. My Orders open karo.
  3. Delivered order ko find karo.
  4. Request Replacement par click karo.
  5. Replacement reason select karo.
  6. Agar zaroori ho to description mein problem explain karo.
  7. Submit Request par click karo.

Replacement request submit hone ke baad request status support/admin team ke through update kiya ja sakta hai.

👤 Account / Login problem

▼

Agar account mein problem aa rahi hai:

  1. Apna email aur password carefully check karo.
  2. Correct login page se login karne ki koshish karo.
  3. Agar account nahi hai to Create Account se signup karo.
  4. Signup ke baad apne account mein login karo.

🛒 Cart kaise use karein?

▼

Cart mein product add karne ke steps:

  1. Apna product open karo.
  2. Add to Cart par click karo.
  3. Cart page open karo.
  4. Yahan product quantity increase ya decrease kar sakte ho.
  5. Product remove bhi kar sakte ho.
  6. Checkout par jaakar order place karo.

❤️ Wishlist kaise use karein?

▼

Wishlist ka use un products ko save karne ke liye kiya ja sakta hai jinhe tum future mein purchase karna chahte ho.

  1. Product details page open karo.
  2. ❤️ Wishlist option par click karo.
  3. Product wishlist mein save ho jayega.
  4. Baad mein account ke Wishlist section se product dekh sakte ho.

🔍 Product search kaise karein?

▼

Product search karne ke steps:

  1. Homepage par search bar open karo.
  2. Product ka naam type karo.
  3. Search suggestions mein product select kar sakte ho.
  4. Search button par click karo.
  5. Available products results mein dikh jayenge.

Product ka naam thoda galat type hone par bhi search system similar product find karne ki koshish karta hai.

🏪 Seller kaise banein?

▼

Seller banne ke basic steps:

  1. Seller section open karo.
  2. Seller account ke liye signup karo.
  3. Apni required information submit karo.
  4. Seller account mein login karo.
  5. Seller dashboard se products add karo.
  6. Product information aur image add karo.
  7. Product submit karo.
  8. Admin approval ke baad product website par visible hoga.

❓ Frequently Asked Questions

▼

Q: Kya main order track kar sakta hoon?

Haan, My Account → My Orders mein jaakar order tracking information dekh sakte ho.

Q: Replacement kab request kar sakte hain?

Delivered order ke liye available hone par Request Replacement option se request submit kar sakte ho.

Q: Kya Cash on Delivery available hai?

Haan, checkout ke time available payment methods mein COD select kiya ja sakta hai.

Q: Kya main product wishlist mein save kar sakta hoon?

Haan, product page se Wishlist option use karke product save kar sakte ho.
